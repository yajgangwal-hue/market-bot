## B. Finding 1 — the sealed accounting is not merely order-dependent, it is
## undefined for the bucket

The seal fixes two things that cannot both hold:

1. the attribution order is **production's own** — `… → 12-position cap →
   correlation bucket → SIGNAL → sizing → cash → …`
2. the accounting must reconcile to **the candidate universe of 5,087**

**In production the guard runs BEFORE the signal.** A symbol denied by the
12-position cap or the correlation bucket never has its signal computed, so
production never learns whether it was a candidate at all.

Measured on the instrumented run:

| | count |
|---|---|
| guard calls | **552,943** |
| signal calls (guard passed) | **457,637** |
| **guard denials — candidacy never determined** | **95,306** |
| of those signals, valid buys | **1,539** |

**Under production's true order the number of *candidates* rejected by the
bucket is undefined.** My attribution returns bucket = 0 not because the bucket
blocks nothing, but because **no candidate can ever reach it** — candidacy is
established one step later. Attributing those 95,306 to the bucket would be
asserting a candidacy production never evaluated, which §3 of the brief
explicitly forbids.

It follows that **`bucket-forensics`'s 5,087 universe cannot have been produced
by production's ordering.** It must have evaluated the signal first for every
symbol-session and then applied guards to that set — the opposite order. Both
accountings are internally valid; they describe different populations.

| accounting | taken | bucket | cash | other | total |
|---|---|---|---|---|---|
| `bucket-forensics` (signal-first) | 698 | 3,025 | 163 | 1,201 | **5,087** |
| production order (guard-first) | 698 | **undefined** | 841 | — | **1,539** |

Both contain exactly 698 accepted, which is the consistency check that passes.
Everything else differs because the denominators are different populations.

**I did not pick one and proceed.** The seal names the production order, and
under it the reconciliation the seal also demands cannot exist.

## C. Finding 2 — the premise does not hold: the entry cap is nearly inert

This is independent of Finding 1 and is measured directly from the frozen run.

| | |
|---|---|
| trading sessions | 2,684 |
| sessions with ≥1 fill | 507 |
| total fills | 698 |
| **mean fills per session** | **0.260** |
| sessions with exactly 1 fill | 364 (13.56%) |
| sessions with exactly 2 fills | 95 (3.54%) |
| **sessions reaching 3 fills** | **48 (1.79%)** |

**The 3-entries/day cap can only bind on the 48 sessions that actually reached
three fills — 1.79% of the decade.** On the other 98.21% it was never touched
and blocked nothing.

The frozen baseline averages **0.26 fills per session against a cap of 3**. It
is not running into the entry cap; it is nowhere near it.

### What is actually binding

Of the 1,539 candidates that reach the signal under production's order:

| first binding reason | n | share |
|---|---|---|
| **cash** | **841** | **54.65%** |
| accepted | 698 | 45.35% |

**Cash is the binding constraint on candidates that get that far — not the
entry cap.** `bucket-forensics` recorded cash at only 163 because its
signal-first ordering let 3,025 be absorbed by the bucket before cash was ever
tested. Same system, different question, different answer.

## G. What a corrected registration would need

Not registered, not proposed for execution — stated so the decision is yours.

**The contradiction is resolvable, but only by choosing explicitly which
question is being asked**, and the two are different:

1. **"What does production's decision sequence do?"** — then the guard-first
   order stands, bucket attribution is permanently undefined, and the honest
   finding is that **cash binds 54.65% of candidates that reach the signal**
   while the entry cap binds on 1.79% of sessions. This needs no new
   registration; it is what this run already measured.
2. **"Which constraint would bind if every symbol-session's candidacy were
   known?"** — then the signal must be evaluated first for all symbol-sessions,
   as `bucket-forensics` did, producing the 5,087 universe. That is a
   counterfactual ordering, not production's, and must be labelled as such.
   H-0015 sealed the production order, so answering this requires an amended or
   successor registration that says so openly.

**The more useful redirection, on this evidence:** the next capacity question
is not the entry cap. It is **cash/notional**, which binds 841 of 1,539
candidates. That was not what H-0015 was registered to examine, and I am not
examining it under this seal.
