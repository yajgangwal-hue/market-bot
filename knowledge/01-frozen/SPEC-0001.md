## What it is

The single statement of what information each decision may use and when it
acts. It applies to the emulator (`portfolio.py`), the live loop
(`autotrade.py`) and any future research harness. It records existing intent
and changes nothing by itself: “This specification changes no code and
authorises no code change.” — [source](../../docs/SPEC-0001-decision-boundary.md)
